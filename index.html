Data & safety

Fee records and student data deserve more care than an Excel file.

Every change is logged, permanently

Who changed what, and when — every edit to a fee, mark, or record leaves a permanent trail. If a number looks wrong, you can see its entire history.

Each school's data stays separate

Tulips serves multiple schools, but isolation is enforced in the software's core — one school can never see another's records.

Role-based access, enforced everywhere

A teacher can't open fee records; an accountant can't edit marks. Every single action is checked against the person's role — there are no side doors.
